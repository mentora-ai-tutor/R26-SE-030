⬡ System Architecture

◈ Microservices Inventory

User Service

LMG Service
Node.js 20 · Express
Learning Material Generator. Receives mastery profiles, queues generation jobs via n8n, stores structured materials (lessons, quizzes, flashcards, code examples).
:5012 GET /health MongoDB n8n
📊
Assessment Agent (AME)
Node.js 20 · Express
Assessment & Mastery Evaluation. RAG-based concept coverage scoring, Ollama-powered embedding and inference, n8n workflow triggers for material generation.
:5002 GET /health Ollama n8n
👥

Python 3.11 · FastAPI
Collaborative peer learning features. Matches students, facilitates study groups, and manages shared learning challenges and progress tracking.

Python 3.11 · FastAPI
GitHub repo analysis, adaptive quiz engine, mastery profiling, concept-graph diagnostics. Routes between Gemini and Ollama with automatic fallback to seed bank.

Java code execution engine. Compiles and runs Java in a sandboxed environment, powers the Code Sandbox and practice challenges with AI-powered feedback.

⬢ Containerisation Strategy

All six services are packaged as Docker images with lightweight base images. Each includes a .dockerignore to exclude test files, secrets, and IDE config.

⊞ Docker Compose Orchestration

Development

docker-compose.yml

  • Builds from local source
  • Hot-reload friendly
  • KAA port: 5007
  • External deps via host.docker.internal
  • Full CORS for localhost dev

Production

docker-compose.prod.yml

  • Pulls pre-built images from GHCR
  • No build contexts — images fetched
  • KAA port: 8001
  • CORS restricted to mentora.kaweesha.com
  • External TLS proxy assumed

Service Startup Order

user-service → lmg-service assessment-agent → knowledge-analysis ← ai-engine | peer-learning (independent)

◉ External Dependencies

MongoDB

Persistent storage for all stateful services — user accounts, mastery profiles, quiz sessions, learning materials, sandbox attempts, career predictions.

Atlas (free M0) Self-hosted

Local LLM inference engine. Runs llama3:8b for general NL tasks and qwen2.5-coder:7b for code understanding. Accessed via host.docker.internal:11434.

8–16 GB RAM GPU optional

n8n

Workflow automation engine. Triggers material generation pipelines for the LMG and assessment agents. Runs as a Docker container or n8n Cloud.

▶ Deployment Workflow

Local Development

# 1. Start external deps on host
mongod --dbpath ./data/db &
ollama serve &
docker run -d -p 5678:5678 n8nio/n8n &

# 2. Launch the full stack
cd mentora-backend
docker compose up --build -d

# 3. Verify all services
curl http://localhost:3001/health
curl http://localhost:5012/health
curl http://localhost:5007/health
curl http://localhost:5010/health

Production (via GHCR)

# 1. Clone on production host
git clone https://github.com/<owner>/mentora-backend.git
cd mentora-backend

# 2. Configure environment
cp services/user\ service/.env.example \
   services/user\ service/.env
# ... edit each .env with production values ...

# 3. Deploy using pre-built images
docker compose -f docker-compose.prod.yml pull
docker compose -f docker-compose.prod.yml up -d

# 4. Verify
curl http://localhost:5007/health
