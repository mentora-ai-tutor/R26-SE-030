2. Scope & Approach

In scope

  • Test architecture: per-service folders under test/<service>/ with unit/, integration/, performance/ layers.
  • Node services: user-service & assessment-agent (Jest), learning-generator (node:test).
  • Python services: knowledge-analysis, peer-learning, ai-engine (pytest).
  • Functional verification of the frontend deliverables (delete, dashboard, settings, dialogs).

Out of scope / notes

  • Live end-to-end tests with real databases/LLMs (covered by the docker-compose stack, not automated here).
  • UI automation (Playwright/Cypress) — not yet established.
  • Load/stress testing of the full distributed stack (performance here is per-module regression timing).

6. What Each Layer Covers

Unit

  • user-service: Student model (pre-save hashing, comparePassword, softDelete, lockout), student-ID generator, AES/GCM github token crypto, OAuth state HMAC, device parser.
  • learning-generator: material query builder & stats aggregation, apiResponse helpers, per-controller ownership guards.
  • assessment-agent: RAG chunking + cosine similarity, embedding service caching, mongo dashboard aggregations, assessment & rag controller logic, error handler.
  • knowledge-analysis: LLM provider choice, prompt building, JSON extraction fallbacks, career classifier, diagnostic report, mastery contract, quiz engine.
  • peer-learning: agent response parsing, syntax/complexity logic, RAG extraction fallbacks, task generation helpers.
  • ai-engine: Ollama JSON repair/parsing + code-model retry, Java executor arg building & run/error/timeout flows, pydantic request models.

Integration

  • Endpoints exercised via supertest / FastAPI TestClient with persistence and external clients mocked (no real DB/LLM/network).
  • Auth boundaries verified: 401 missing/invalid token, 403 cross-student access, 404 not-found, 400 validation, 200 happy paths.
  • Key flows: student profile/preferences/password, materials fetch/delete (incl. hard-delete progress cascade), progress stats, knowledge-profile & mastery endpoints, RAG retrieval, sandbox/challenge endpoints, peer-learning sessions & quiz start/submit/summary, ai-engine code-review/execute/feedback.

Performance

  • Timing regressions with generous bounds: ID generation ×1000, password hashing ×100, query-builder ×10k, JSON parsing ×50–100, classifier ×200, endpoint round-trips. Typical measured times are in the low ms range.
